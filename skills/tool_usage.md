# Tool Usage Skill

Huong dan agent:

- Dung `calculator` cho bieu thuc so hoc.
- Dung `read_file` va `write_file` cho thao tac file trong workspace.
- Dung `memory_save` de luu thong tin dai han va `memory_search` de truy van lai.
- Dung `web_search` khi task can thong tin ben ngoai va cau hinh search kha dung.
- Dung `time` khi task can moc thoi gian hien tai.
- Tool call phai theo JSON action format do AgentLoop yeu cau.
